# Luna Video Optimizer

A standalone, ReelRise-inspired optimization layer built for Luna.

It does not require a ReelRise subscription and does not reproduce ReelRise proprietary source code, model weights, hidden formulas, or private datasets.

## Luna defaults

- AI lifestyle + relatable pretty-girl creator
- 10-second videos
- 3.5-second stop-scroll hook
- 9:16 vertical
- Photorealistic continuity
- Fencing paused
- Exact Luna identity lock

## What it does

Given a new video idea, an optional analysis report, and optional historical Luna performance data, the optimizer produces hook candidates, retention warnings, historical performance signals, a 10-second generation prompt, and a controlled testing plan.

## GitHub Actions

Open **Actions -> Luna Video Optimizer -> Run workflow**, enter an idea, then download the generated `luna-video-brief` artifact.

## Learning loop

Luna idea -> optimizer -> generated video -> TikTok / Instagram -> actual performance -> Luna performance data -> next optimization.

The next phase can add automatic TikTok/Instagram analytics ingestion through Composio, normalized engagement and follower-conversion metrics, experiment IDs, pattern detection, prompt libraries, and weekly learning reports.
